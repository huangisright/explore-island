# 數學探索島

互動探索站的「預測 → 操作 → 紀錄」版本，名單上的學生用 Google 帳號登入後，紀錄存到雲端。

- `index.html`：入口地圖
- `passport.html`：探索紀錄本（同一張地圖，標出走完的島）
- `g*.html`：30 章單元頁（七上到九下）
- `teacher.html`：老師頁面（跨章總表、單章紀錄、學生名單；可篩班級、匯出 CSV）
- `upload.html`：教材上傳（只有管理者能用）
- `try-*.html`：試做中的空殼頁（見下）

## 更新

`python3 _原始碼/build.py <互動版網站資料夾> .`

## 登入後才載入內容（空殼頁）

空殼頁本身沒有教材：登入、而且在名單上（或是老師帳號）之後，才從 Firestore 的 `content/<slug>` 把內容載進來，畫面上會淡淡鋪一層登入者的姓名與帳號。

`python3 _原始碼/build.py <互動版網站資料夾> . <內容檔資料夾>`

- `build.py` 的 `GATED`：這些單元只輸出空殼頁，教材寫成 `<內容檔資料夾>/<slug>.json`。**內容檔資料夾不要放進這個 repo。**
- `build.py` 的 `TRIAL`：照舊輸出完整頁，另外多做一份 `try-<slug>.html` 空殼頁先測。
- 內容檔由管理者在 `upload.html` 選檔上傳；同一章再傳一次就是更新。

每一章的預測問句與判斷題寫在 `_原始碼/units_*.py`，新增一章要在 `build.py` 的 `BUILT` 補上。
資料庫權限規則在 `_原始碼/firestore.rules`，改了要貼到 Firebase 主控台發布。
