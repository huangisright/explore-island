# 數學探索島

互動探索站的「預測 → 操作 → 紀錄」版本，名單上的學生用 Google 帳號登入後，紀錄存到雲端。

- `index.html`：入口地圖
- `passport.html`：探索紀錄本（同一張地圖，標出走完的島）
- `geo.html`、`geo-stars.html`：幾何拾光（群島海圖／星座圖兩種看法，各節連到 GiftedMath 的動態頁）；網址加 `#teacher` 開一次，這台電腦才會出現教師視角按鈕。原檔在 `_原始碼/`，build 時原樣複製
- `g*.html`：30 章單元頁（七上到九下）
- `teacher.html`：老師頁面（跨章總表、單章紀錄、學生名單；可篩班級、匯出 CSV）
- `upload.html`：教材上傳（只有管理者能用）
- `report.html`：報告島（章後延伸報告）：學生選題、交海報、看老師回饋
- `report-show.html`：展示廳：海報展示；老師看繳交狀況、排報告順序、報告模式（投影）、評分與互評、匯出 CSV；台下同學在這裡給星星
- `try-*.html`：試做中的空殼頁（見下）

## 更新

`python3 _原始碼/build.py <互動版網站資料夾> .`

## 登入後才載入內容（空殼頁）

空殼頁本身沒有教材：登入、而且在名單上（或是老師帳號）之後，才從 Firestore 的 `content/<slug>` 把內容載進來，畫面上會淡淡鋪一層登入者的姓名與帳號。

`python3 _原始碼/build.py <互動版網站資料夾> . <內容檔資料夾>`

- `build.py` 的 `GATED`：這些單元只輸出空殼頁，教材寫成 `<內容檔資料夾>/<slug>.json`。**內容檔資料夾不要放進這個 repo。**
- `build.py` 的 `TRIAL`：照舊輸出完整頁，另外多做一份 `try-<slug>.html` 空殼頁先測。
- 內容檔由管理者在 `upload.html` 選檔上傳；同一章再傳一次就是更新。

每一章的預測問句與判斷題寫在 `_原始碼/units_*.py`，新增一章要在 `build.py` 的 `BUILT` 補上。
資料庫權限規則在 `_原始碼/firestore.rules`，改了要貼到 Firebase 主控台發布。

## 報告島（章後延伸報告）

24 章、每章 6 題（題庫 `_原始碼/ext-questions.json`，從學習單設計資料夾的 `_原始碼/延伸題庫.json` 複製，只有學生看得到的欄位）。

- 學生：選章 → 選題（同一題不限人數）→ 交一句話結論＋海報照片（最多 3 張，瀏覽器先壓縮再存進 Firestore）＋選填連結；截止前都能改。
- 老師（展示廳）：繳交狀況（每題幾人、誰還沒選）、截止收件、報告順序（拖拉／↑↓／隨機／依座號）、▶ 報告模式（一位一位投影，切到誰就開放同學評分）、評分（批改看五件事，每項 1～3，可勾「學生看得到」）、匯出 CSV。
- 同學互評：只有台上那一位正在報告時能送（1～3 顆星＋一句話）；老師看得到是誰寫的，學生只看得到自己寫的。
- 原圖備份到老師的雲端硬碟：部署 `_原始碼/drive-upload.gs`（檔案開頭有步驟），把網址貼到 `firebase-config.js` 的 `window.ISLAND_DRIVE`。沒設定就只存在 Firestore。

資料：`ext/{章}`（順序、台上是誰、截止）、`ext/{章}/subs/{uid}`（選題與繳交）、`…/img/{0,1,2}`（照片）、`ext/{章}/grades/{uid}`、`ext/{章}/peer/{報告人}_{評分人}`。規則在 `firestore.rules`。
